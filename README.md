# Homebrew tap for Kopi

[Kopi](https://github.com/keyute/kopi) is a coding-agent CLI.

```sh
brew install keyute/tap/kopi
```

`Formula/kopi.rb` is generated by Kopi's release workflow from `.github/homebrew/kopi.rb` in that repository and is overwritten on every release. Change the formula there, not here.
