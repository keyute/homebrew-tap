# Homebrew tap guidelines

## Tap

- `keyute/homebrew-tap` serves `brew install keyute/tap/kopi`. Its one formula, `Formula/kopi.rb`, downloads the prebuilt binaries from Kopi's GitHub release.
- `Formula/kopi.rb` is generated by the release workflow of keyute/kopi from `.github/homebrew/kopi.rb` there and pushed to `main` with a deploy key. Every release overwrites it, so change the formula in keyute/kopi, not here.
- The one exception is a formula-only fix for an already released version: edit it here and mirror it into the template in keyute/kopi.
- There is no `Formula/` directory until Kopi's first release; everything here must work without it.

## Workflow

- Never commit, tag or push.
- Workflow actions are pinned to commit SHAs with a comment naming the release, the workflow has `permissions: {}` and each job takes only the permissions it needs.
- The `ci` job in `test.yml` is the required status check; the ruleset lets the release deploy key bypass it so the release push lands.
